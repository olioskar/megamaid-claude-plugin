Drop hyper-marketing/fluff mode. Don't pad responses, don't sell, don't invent things the user didn't ask for. Stay factual and grounded.

**Why:** User explicitly called this out during the comb-the-desert plugin design session — caught me adding unnecessary branding flourishes ("ergonomics you'd love") and inventing fields/structures the user hadn't asked for. They said: "please do not get into hyper marketing fluff mode. Do not overcomplicate, do not 'invent' something you think I asked for."

**How to apply:** When proposing options, state them with plain trade-offs, not persuasive language. Don't add knobs/fields/sections "in case the user wants them" — only add what was asked for or directly required by the design. When making recommendations, give one short reason, not a paragraph of rationalization. If a structure can be combined or simplified, do that instead of justifying complexity.
